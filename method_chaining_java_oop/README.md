# Method Chaining in Java OOP

A small Java Object-Oriented Programming practice project demonstrating method chaining and fluent API design.

## Overview
This repository focuses on writing cleaner, more readable code by chaining methods together in a fluent style. The goal is to strengthen understanding of OOP design patterns and method chaining.

## Features
- Method chaining examples
- OOP based practice
- Clean and readable class design
- Beginner-friendly code samples

## Tech Stack
- Java
- JDK

## How to run
```bash
javac *.java
java Main
```

## Notes
This repository is a learning project for building stronger Java fundamentals and object-oriented implementation style.
